# Methodology (generated 2026-10-13 17:43; pipeline v1.5.0)

**Gene panel:** PROVISIONAL (not confirmed by the user); version hash `03d5812616df`. A PROVISIONAL panel is NOT the original project panel.

## Data
- TCGA-COAD: GDC API (`/files`, `/cases`), open-access *STAR - Counts* gene-level files; value used = `tpm_unstranded`, protein-coding genes, duplicate gene names averaged, transformed log2(TPM+1). Primary tumour = barcode sample code 01 and API sample_type 'Primary Tumor'; per patient the lexicographically first sample barcode (then file name) is kept. File MD5 checked against GDC.
- OS: days_to_death if Dead; if Alive, diagnoses.days_to_last_follow_up, else the maximum follow_ups.days_to_follow_up; months = days/30.4375; valid if time>0 and event known. Stage: AJCC I-IV -> 1-4 (sub-stages merged). Age: age_at_diagnosis/365.25. TCGA DFS and MSI are not retrieved.
- GEO (GSE39582, GSE17536, GSE14333): series matrix + platform annotation. Expression scale inferred (max>100 -> log2(x+1)). Probes -> gene symbols; probes without symbol or with multiple genes dropped; per gene the probe with highest mean expression kept (outcome-free). Clinical fields mapped by regular expressions over characteristics keys (see data_dictionary.csv; override in config `geo.overrides`). Time units taken from field names, otherwise assumed months (flagged).
- GDSC2: fitted dose-response (LN_IC50 natural-log µM, AUC) + RMA basal expression; CRC lines = TCGA_DESC == 'COREAD'; joined on verified COSMIC IDs; duplicate (line,drug) pairs averaged; missing responses never imputed.
- CTRPv2: curves/experiment/cell-line/compound tables joined by IDs; CRC = site 'large_intestine'; AUC averaged over experiments; cell lines matched to GDSC expression by normalised name; exploratory.

## Harmonisation
RNA-seq and microarray values are never pooled. Each cohort is analysed separately. For external prognosis evaluation, the selected genes are z-scored **within each external cohort** (label-free, cohort-specific standardisation) and multiplied by frozen TCGA coefficients. No outcome from a validation cohort is used for preprocessing, selection, tuning or thresholds.

## Prognosis (Novelty 2)
Eligible features = panel genes present in TCGA and all loaded GEO cohorts (gene availability only). In training data: z-score (training mean/SD) -> univariate Cox per gene -> keep p < 0.1 (fallback: lowest-p 3 genes, flagged) -> ridge Cox (lifelines `penalizer`, l1_ratio=0) with penalizer chosen from [0.05, 0.5, 5.0, 50.0, 500.0] by 3-fold inner CV C-index. Risk = sum(coef x z). Model, preprocessing parameters and thresholds are frozen to `data/processed/frozen_prognosis_model.json` before any external cohort is touched. TCGA CV (5-fold x 2) repeats the whole screening+tuning+fit inside each training fold. Clinical model: Cox on age (years) + stage (1-4); combined: age + stage + risk. Metrics: Harrell C-index (bootstrap 500 95% CI), HR per SD of risk, calibration slope (Cox coefficient on the linear predictor; ideal 1), log-rank for high vs low at the training median. Endpoint: OS; if a cohort has no OS, DFS/RFS is used and flagged as endpoint-mismatched/exploratory.

## Specificity benchmarking (Novelty 1)
200 random gene sets (same size as the eligible panel, drawn without replacement from expressed genes [TCGA mean log2TPM>=1] present in all cohorts, excluding panel and proliferation genes; seed 42) pass through the **identical** procedure (screening, tuning, fit in TCGA, frozen application to each external cohort). Empirical one-sided p = (1 + #controls with C >= observed)/(1 + N). A proliferation-marker set (author-compiled, not a published validated signature) is run identically as an exploratory comparator. An association with survival alone is not evidence of ferroptosis specificity.

## Classification
Target: dMMR (1) vs pMMR (0) from GEO characteristics (verified labels only). L2 logistic regression (inner CV for C) with in-fold standardisation; patient-level stratified 5-fold CV x 2 repeats (out-of-fold probabilities averaged); metrics at probability threshold 0.5 (prespecified). AUC CI by bootstrap over patients. 200 random gene-set controls with the same pipeline. FerroScore AUC is descriptive (orientation not prespecified).

## Drug response (Novelty 3)
FerroScore = mean z(driver genes) - mean z(suppressor genes), z-scored across the cell lines analysed; requires >= 80% coverage per role. Spearman correlation vs LN_IC50 and AUC per drug (n >= 15), 95% CI by Fisher/Bonett-Wright, Benjamini-Hochberg q across all tested drugs per metric (and separately across prespecified primary compounds). Prespecified: ML162, ML210, RSL3; everything else exploratory (erastin explicitly exploratory). Models (n >= 30 lines): mean baseline, FerroScore-linear, panel ridge; 5-fold x 3 CV, one row per cell line so splits are cell-line-level; drugs chosen by sample size only. Prespecified tiers: primary (ML162, ML210, RSL3) and clinical (5-fluorouracil, oxaliplatin, irinotecan); all other drugs exploratory. For prespecified drugs with >= 30 lines a sensitivity CLASSIFIER is also fitted (sensitive = LN_IC50 below that drug's median; L2 logistic regression on the panel genes or on FerroScore alone; out-of-fold AUC, 3 repeats). The endpoint is in-vitro cell-line sensitivity, never a clinical dose or response. **Cell-line IC50 is not a clinical dose; no dosing or treatment recommendation is made.**
The dMMR vs pMMR classifier above tests whether the panel carries MSI information; it is not a classifier of a ferroptosis state.
CTRP replication: for compounds shared by normalised name, directional concordance and p in CTRP; 'replicated' = GDSC AUC p<0.05, same sign, CTRP p<0.05. Different assays/cell-line panels are not interchangeable; treat as exploratory.
